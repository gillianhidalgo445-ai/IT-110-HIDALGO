HTML DOM

The HTML DOM (Document Object Model) represents this page as a tree of nested elements. For example, this <section> is the parent of the heading and paragraphs inside it, and the browser builds this structure automatically when it parses the HTML file.

This paragraph has an id attribute, so it can be selected individually in the DOM tree.
